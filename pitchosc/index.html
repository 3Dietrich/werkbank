Ein Doppelklick im Finder/Explorer öffnet sie über file:// — die ES-Module dieser Seite laden so nicht (Browser-Sicherheit). Falls im Ordner ein Start-Skript liegt (*.command), reicht ein Doppelklick darauf. Sonst im Terminal von Hand:

cd <Projektordner> && python3 -m http.server 8002 && open http://localhost:8002/

Takt + Metronom

Transport / Tempo · Takt / Metronom — Neu-Port (P1–P4) Zwei Gruppen aus einer deklarativen defs-Quelle (gemappt aus taktgeber), gezeigt mit teslacoils Fabriken. e = Anordnen-Modus (Gruppen/Controls frei verschiebbar). Rechtsklick auf Gruppen-Titel = Settings, Rechtsklick auf ein Control = dessen Optik. Gezogene Werte = „Knob ohne Knob". Der Header-Schalter ⌨ Tasten/MIDI zeigt/ändert Tastenbelegung + MIDI-Learn über allen Controls. ▶ (oder die belegte Taste) startet das Metronom — echter Ton aus taktgebers metro.js/clock.js.
